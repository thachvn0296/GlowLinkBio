# GlowLinkBio

A simple static landing page for sharing social links and contact info. The page is implemented as a single `index.html` file with built-in CSS styling.

## Features

- Responsive mobile-first layout
- Glassmorphism-style card UI
- Social links using Font Awesome icons
- Easy single-file customization

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npx http-server .
```

Then open the URL shown in the terminal, typically `http://127.0.0.1:8080`.

### Alternative

You can also open `index.html` directly in a browser for a local preview without running a server.

## Project Structure

- `index.html` — main page markup and styles
- `package.json` — dependency listing
- `package-lock.json` — exact dependency versions
- `assets/` — optional static assets used by the page

## Customization

Edit `index.html` to update:

- profile name and bio
- social icon links
- link cards and URLs

## Notes

This is a static frontend page only; no backend or build step is required.
